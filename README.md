# خطة محتوى ٢٠ يوم — إدارة الحملات الإعلانية

- `content/calendar.md` — الخطة كاملة بالنصوص لكل منصة
- `content/plan.json` — مصدر المحتوى (يقرأه الرندر وروتين Buffer)
- `brand/brand-guide.md` — هوية الانستجرام
- `designs/` — التصاميم الجاهزة (انستجرام 1080×1350، لينكدإن 1200×1200، X 1600×900)
- `.claude/skills/` — السكلات: كتابة المحتوى السعودي، الهوية، الرندر، تعبئة Buffer
- `brand/handles.json` — اليوزرات اللي تطلع أسفل التصاميم

إعادة الرندر بعد تعديل اليوزرات: `cd scripts && npm i && cd .. && node scripts/render.mjs`

## التشغيل التلقائي
روتين يومي (٧:٤٧ص بتوقيت السعودية) يشغّل سكل `content-autopilot`:
١. يقرأ الأماكن الفاضية في Buffer (١٠ بوستات مجدولة لكل منصة بالباقة المجانية).
٢. إذا بقى أقل من ١٠ أيام غير مجدولة بالخطة، يكتب ١٠ أيام جديدة باللهجة السعودية (بعد بحث عن آخر التحديثات) ويصمّمها ويرفعها.
٣. يجدول اللي يفضى لكل منصة، فالنشر يومي وما يوقف.
